# SPK V5-T3l/m/n: Goal identifiability and receiver-credit alignment (research)

**Scope:** research-only add-on to the T3h C-authored A1b return channel and the T3i/j/k host-owned contextual controller. None of Core, Network, Compiler, Architecture v1, A1b, BV v0e, T3a–T3k source or frozen manifests is modified.

## T3l: paired worlds, an information-limited impossibility witness

Make two engineered worlds with **identical contemporaneous light inputs**, the **same CO2 proxy observation at C**, the same C-origin A1b instruction-computed feedback, the same network disruptions and the same random seed for the T3i host-owned selector. Keep the auditor-only goal equal to the C proxy in world one and inverted in world two. The goal is never accessible to A, C or the credit registry. Both worlds must produce identical A-choice-and-C-credit trace digests, the same credit-ledger hash and the same learned registry weights. Their goal-correct counts must sum to the episode count. This is a **constructed non-identifiability counterexample for C-only observations**: genuine local feedback cannot guarantee fitness to an unobserved opposite external goal. It is *not* a physical-world generalization study and does not rule out learning from additional goal evidence.

## T3m: public original UCI posthoc discordance attribution

On the first 1200 *actual consecutive* readings per original indexed UCI file, run frozen A1b T3h for every A choice selected by the C-credit-only T3i online policy. A's decision is reserved **before** C's independent CO2 sensor is supplied; PHOTO labels are consulted only after the A1b run and controller register operation and never used for updates. Reconcile C-origin rewards (+1/-1) against both the CO2 proxy and the independent photo occupancy label. Distinguish a **misleading positive** credit (C rewards a photo-wrong decision) from a **misleading negative** credit (C penalizes a photo-correct decision). Both types together must exactly equal proxy/photo label disagreement for an intact, binary-outcome event. Aggregate by date and A's two-bit light context as diagnostics; they are not independent statistical trials.

Three SHA-256 pins bind the *original bytes* of the historical files. Their known public labels have been consulted in prior SPK T3 research. This is **not a fresh test, blind holdout, cryptographic sensor attestation, trusted objective authority, or native BV transport**.

## T3n: explicit promotion denial

Even if a constructed world produces high local C reward, and even if the published UCI photo goal sometimes agrees with it, the gate **forbids** interpreting verified receiver authorship as alignment, blind generalization or native neuronal learning. The T3i registry remains host-owned; the C sensor's CO2 bit remains host-thresholded. Crediting a locally authentic verdict does not independently attest that its proxy is the objective.

Run `bash search/spk_v5_t3lmn_goal_alignment_gate.sh ~/Scaricati/occupancy /tmp/spk-v5-t3lmn-goal-alignment.json`. The report is create-only. Gate checks inherited source pins, new SHA pins, deterministic paired-world replay, invalid-world and forged-report rejection, original UCI source hashes, old regressions, frozen A1b/BV, and a byte-exact comparison against the canonical reference. Report generated from already-public data must **never** be used for production promotion or a prospective success claim.
