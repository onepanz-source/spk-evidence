# SPK/* V5-T2h: research-only interleaved semantic-control arbitration

**Status:** Interleaved fork of BV v0e, not a change to frozen BV v0e.

## Technical question

Can a precommitted shadow decision (including a silent action) and the return
semantic-control path share an actual logical clock, PE service, memory and
cross-PE link arbitration with spikes and source-native BV packets, without
falsifying native provenance, skipping costs, or treating non-delivery as
negative reinforcement?

## Design

- A source-pinned, standalone *research fork* of `execute_live_v0e` embeds the
  T2f seven-stage semantic-control route into the *existing tick loop*.
- The source BV v0e file and architecture modules are never changed. The
  research fork shares the actual tick-local `service_used`, `mem_pe_used`,
  `mem_dom_used`, `mem_total`, `pe_total`, `link_used`, `link_fabric_used` and
  `inflight_count` with normal source spikes and reverse BV traffic.
- The host-issued decision token is committed before C demand/closure. The
  C-observer stage requires a **real C terminal channel-9 closure in the
  interleaved run**. Cross-PE semantic-control deliveries travel through the
  shared in-flight heap with positive delay; no synthetic instantaneous ACK.
- Two priority policies: `source-first` and `control-first` (source neuron
  computations always precede link/semantic-control arbitration within a tick).
- Charge one PE grant for each stage, 12 model-memory units and four model
  cross-PE links for a complete route, against real shared capacity. The
  source event engine's native BV resource consumption is separately retained.
- Every delivered semantic reward requires exact temporal comparison with
  T2f's independently rerun frozen A1b receipt. **Mismatch -> abstention**.
- A missing demand, lost message, and unserved decision at the declared
  deadline cannot be converted into a negative reward.
- With semantic-control disabled, the entire source view is compared for
  exact equality to the unmodified BV v0e executor, including resource
  timelines, source states and causal journals.
- The result is deterministic; the test suite recomputes claimed traces and
  rejects forged costs/timestamps/rewards.

## Scope and restrictions

All episodes and demand signals are generated by the authors' synthetic task.
The host still manufactures the decision witness: native neuron A has neither
an adopted decision operator nor an authenticated semantic-control endpoint.
The interleaved engine is a **derived fork**, not the frozen/native scheduler;
its services cannot be called source-native grants. Timing under
`control-first` may change native source computation and even semantic output,
which is precisely why parity must be audited instead of presumed.

This does **not** prove independent task truth, a blindly evaluated RL
improvement, production provenance, real energy consumption, N-node scale,
network liveness, or autonomous program modification. No learning / promotion
is authorized by this milestone.

## Next research gate

Stop extending synthetic arbitration unless independent task evidence or
native interface scope is explicitly supplied. For a meaningful T3 gate,
source-independent reward integrity, a genuinely held-out task and a
bounded learning-policy update protocol are required. Native migration remains
an independent architecture decision, not an automatic result of T2h.
