# SPK BV v1i: Native feedback-silence and objective-polarity boundary

**Research-only.** All frozen Architecture v1/Core/Network/Compiler packages and the native live v0e scheduler are unchanged.

## Motivation / actual native result

The source-bound **v1h** `A.CMP(1) → A.CMP(2)` copy intervention, performed *before* the episode, runs through the actual v0e scheduler and the static `A → B → C` fabric. The native reference is **not** generated by the v1i model. v1i will rerun v1h using the same original inputs and require exact byte-for-byte equality with the v1h source report.

For the bounded two-event fixture, the original network yields 6 forward emissions, 4 routed occurrences (2 A→B; 2 B→C), 2 terminal emissions, 2 ON-mode assessments and 4 ON-mode reverse deliveries. The A-only intervention yields 0 emissions, 0 occurrences, 0 terminal emissions, 0 assessments, 0 reverse deliveries; 2 external-event A batches still execute. Original and modified *individual* OFF/ON forward outputs agree, but original and modified networks differ.

The empty return channel is **not a neutral, positive or negative vote**. When no forward occurrence reaches B or C, neither can make a native event-anchored assessment in this reference. BV delivery count zero therefore makes the signal **unavailable**, not supportive of A's change. No independent scored native receiver judgments have been produced.

## Scoped contract

- Requires source-bound v1h reconstruction, exact byte equality and unchanged original source inputs.
- Rechecks frozen A operand, original/variant transport footprint, changes in five forward counters, both ON/OFF branches, absent judged utility, and the original/variant feedback counts.
- Rejects forged or aliased inputs, missing proof bytes, fabricated A→C route, mutated original nodes, feedback portrayed as learning, and output overwrite. Temp replay artifacts are scoped to a temporary directory.
- Uses strict finite bounded fixture data. A different fixture, topology, runtime build or operator variant needs a **new** contract, not a relaxed validator.
- Demonstrates *criterion dependence* on the real network counterfactual using experimenter-declared terminal objectives: maximize terminal count favors **original**, minimize terminal count favors **variant**, target count 2 favors **original**. These score formulas are **not** receiver values or external oracle truth.
- No online update, rollback, endogenous judgment, causal credit, held-out independence or population generalization is inferred. The absolute counts are fixture counts, not statistically independent observations.

The central future question is how to represent **unobserved** downstream utility for a neuron that silences its descendants. This must be an abstention/missingness state, not a vote. An explicit receiver criterion, prospective comparator/control and permitted feedback-free sensing mechanism would be needed to assign value to silence.

## Install / run on fwork

Extract this incremental archive in `~/workspace/spk-backvalidation-v0`, then run:

```bash
bash search/spk_bv_v1i_research_gate.sh
python -m search.spk_bv_v1i_native_feedback_silence \
  --v1h /tmp/spk-bv-v1h-isolated-network-counterfactual.json \
  --v1g1 /tmp/spk-bv-v1g1-native-original-route-lineage.json \
  --v1f /tmp/spk-bv-v1f-receiver-preference-polarity.json \
  --v1e /tmp/spk-bv-v1e-conditional-receiver-impact.json \
  --v1d /tmp/spk-bv-v1d-native-declared-criterion-13.json \
  --v1c /tmp/spk-bv-v1c-native-sensitivity.json \
  --v1b1 /tmp/spk-bv-v1b1-native-operator-replay.json \
  --v1a /tmp/spk-bv-v1a-symbolic-holdout.json \
  --v0w /tmp/spk-bv-v0w-native-13.json \
  --out /tmp/spk-bv-v1i-native-feedback-silence.json
```

The CLI calls the full v1h native source-bound computation in an isolated temporary destination; the input v1h report must be **byte-identical** to that new computation before the v1i report is published. All other source JSON documents are read-only and cross-checked by v1h. An output file that already exists is rejected.

If using the report-only Python `audit()` locally without the frozen scheduler, this **is not a native recomputation**. The official command writes `native_v1h_recomputation_verified_in_this_run: true` only after the native byte comparison passes. Keep this field absent or false for any offline preview.

## Next scientific gate

Derive an explicit, receiver-local, testable criterion that can evaluate *absence* as an outcome without fabricating incoming events. Test whether such an objective can be preregistered and evaluated prospectively under the same bounded original/variant control and with a potential **unknown/abstention** result. Then evaluate whether actual reverse feedback can affect A's later decision without invalidating the frozen source or conflating passive absence with approval.
