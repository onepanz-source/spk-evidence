# SPK V5/T16: bounded staged causal learning and ownership

## Research question

Can the restricted T15 gain from an A-computed verdict survive transfer from
an atomic Python episode into a multi-event, crash-recoverable C→world→A→B→C
scheduler with research-owned, versioned P authorization?

## Acceptance criteria (precommitted from T15)

* Reproduce exactly T15's five condition totals and inverted-actuator test;
  independently replay the original T15 implementation.
* Compare 60 individual (30 adaptive + 30 frozen) heldout C choice and outcome
  sequences, thresholds and credit counts against T15.
* Keep P immutable for *every* heldout evaluation, across restart.
* Demonstrate distinct durable C, world, A, B and credit dispatch stages;
  tampering, duplicate, stale and lost feedback never produce credit.
* Verify memory write fence, versioned mode/capacity, crash recovery and
  deterministic reports on the same full source checkout.
* Preserve SHA source pins, full accumulated regression, no native promotion.

## Threat and authority model

One host-controlled SQLite process, not independent mutually distrustful
actors. C never takes a per-trial host-supplied reward or right action. A's
verdict is reconstructed by the original SPK PE fragment from Python-encoded
absolute-distance sensor features. The world is deterministic and authored by
the test harness. Receipt delivery can be corrupted by tests.

T16 **does not** claim original A1d access for thermal P updates. The T13
original case uses binary goals 11/12; T15/T16 use setpoints 3..12. Neither
is a drop-in translation of the other. Nor does T16 adopt original BV
transit/authenticated sensory observations. These are explicit integration
requirements for a subsequent, separately validated versioned runtime.

## Scientific interpretation

Only the limited within-dynamics odd/even thermal split may be supported.
The reversed-actuator result shows dependence on a known signed monotone law.
A positive gate does NOT mean general learning, native SPK learning, hardware
performance, or independence from privileged host influence.

## Deployment restrictions

Research-only. No external actuators, no network or device controls, no
migration of original P state. Frozen Algebra, Compiler, Core, Network,
Architecture, and BV-v0e are SHA-pinned and unchanged. The historical 94%
completion estimate is not updated by this work.
