# SPK Algebra

Experimental project for the computational search of a minimal,
compositional set of spike/event-driven primitives.

## Initial objective

Define and test a candidate SPK/v0 basis:

- SPK/MERGE
- SPK/DELAY
- SPK/ACC
- SPK/DECAY
- SPK/CMP
- SPK/EMIT
- SPK/RESET

The project will investigate:

1. compositional expressiveness;
2. functional equivalence between SPK programs;
3. canonicalization and rewriting;
4. redundant primitives;
5. minimal efficient bases.

No neural-network training is part of the initial phase.
