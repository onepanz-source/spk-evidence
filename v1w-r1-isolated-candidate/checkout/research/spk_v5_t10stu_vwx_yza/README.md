# T10STU / T10VWX / T10YZA — Genuine Native Memory Contract Surface Readiness

This is a **read-only source-surface discovery checkpoint**, not a native SPK Memory Contract implementation or an API adapter that grants native credit.

* T10STU: AST-only survey of candidate original Python Memory Contract source in the authentic local checkout; its paths, SHAs, exports and names are evidence **only**. Code is never imported or executed.
* T10VWX: narrowly scoped `C/P/execute` typed request and categorical rejection of reference-grant promotion, even when the privileged host claims a native issuer.
* T10YZA: byte-exact T10JKL report regeneration, source SHA custody, dedicated negative tests, and explicit adoption blockers.

The source survey may find more candidate files on fwork than in the partial sandbox; this is an expected environment-dependent **read-only inventory**, and both independent fwork runs must match. No inferred API contract or native authorization is claimed. No frozen source files are edited.

Source discovery is not permission, a function name is not a grant, and a SHA alone cannot authenticate a privileged hostile host. Full adoption requires independent native code review, a versioned Memory Contract API, a real P-owner transaction and native provenance.
